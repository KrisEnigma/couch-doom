**Download the file for your system below.** No Python needed. Builds aren't code-signed, so your OS may ask you to approve the first launch.

GitHub lists release assets alphabetically, so Windows sits near the bottom of that list. Prefer the links here (Windows first); the `.sha256` files and macOS ZIPs stay in the asset list for the in-app updater.

- **Windows:** [`CouchDoom-__TAG__-windows-x64.zip`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-windows-x64.zip). Extract it and run `CouchDoom.exe`. On the "unknown publisher" warning, choose **More info → Run anyway**.
- **macOS:** [`CouchDoom-__TAG__-macos-arm64.dmg`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-macos-arm64.dmg) (Apple Silicon) or [`CouchDoom-__TAG__-macos-x64.dmg`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-macos-x64.dmg) (Intel, macOS 10.15 or newer). Open it and drag `CouchDoom.app` to Applications. If macOS blocks the first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**. A ZIP of the same build is in the asset list as a fallback for updates.
- **Linux:** [`CouchDoom-__TAG__-linux-x64.tar.gz`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-linux-x64.tar.gz) (PCs) or [`CouchDoom-__TAG__-linux-arm64.tar.gz`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-linux-arm64.tar.gz) (ARM boards such as the Raspberry Pi 4 and 5). Extract it and run `./CouchDoom`. Needs glibc 2.28 or newer (Ubuntu 20.04, Debian 10, RHEL 8 and later).
- **Steam Deck:** the [`linux-x64`](https://github.com/KrisEnigma/couch-doom/releases/download/__TAG__/CouchDoom-__TAG__-linux-x64.tar.gz) file. In Desktop Mode, extract it and add `CouchDoom` to Steam with **Add a Non-Steam Game** so it starts from Game Mode. GZDoom and DoomRunner from Discover are detected automatically.

CouchDoom plays the presets you've already set up in [DoomRunner](https://github.com/Youda008/DoomRunner), [ZDL](https://github.com/lcferrum/qzdl), [Doom Launcher](https://github.com/nstlaurent/DoomLauncher) or [Doom Launcher 667](https://github.com/Realm667/DoomLauncher667). With GZDoom, UZDoom or VKDoom alone, it lists one preset for each IWAD that port can find. It finds them on its own and never changes them. If you use more than one launcher, it asks which to show; you can switch later from the menu.

Once installed, CouchDoom updates itself from inside the app.
