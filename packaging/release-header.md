**Download the file for your system below and start CouchDoom.** No Python or installer needed. Builds aren't code-signed, so your OS may ask you to approve the first launch.

- **Windows:** `CouchDoom-…-windows-x64.zip`, then run `CouchDoom.exe`. On the "unknown publisher" warning, choose **More info → Run anyway**.
- **macOS:** `CouchDoom-…-macos-arm64.dmg` (Apple Silicon) or `CouchDoom-…-macos-x64.dmg` (Intel, macOS 10.15 or newer). Open the disk image and drag `CouchDoom.app` to Applications. If macOS blocks the first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**. A matching ZIP is available as a fallback.
- **Linux:** `CouchDoom-…-linux-x64.tar.gz` (PCs) or `CouchDoom-…-linux-arm64.tar.gz` (ARM boards such as the Raspberry Pi 4 and 5), then run `./CouchDoom`. Needs glibc 2.28 or newer (Ubuntu 20.04, Debian 10, RHEL 8 and later). On Arch you can also build `packaging/aur/PKGBUILD` with `makepkg -si`.
- **Steam Deck:** the `linux-x64` file. In Desktop Mode, extract it and add `CouchDoom` to Steam with **Add a Non-Steam Game** so it starts from Game Mode. GZDoom and DoomRunner from Discover are detected automatically.

You need games already set up in [DoomRunner](https://github.com/Youda008/DoomRunner), [ZDL](https://github.com/lcferrum/qzdl), [Doom Launcher](https://github.com/nstlaurent/DoomLauncher) or [Doom Launcher 667](https://github.com/Realm667/DoomLauncher667), or GZDoom, UZDoom or VKDoom with at least one IWAD. CouchDoom finds those setups on its own and never changes them. If it finds more than one, it asks which to use; switch later from the menu (Start / Esc → Choose launcher).

The menu also covers refresh, title music, menu sounds, Colors, Language, Recently Played, Help, and Quit. Language follows your system on first run when CouchDoom supports it (English, Spanish, Brazilian Portuguese, French, German). Packaged builds can install updates from inside the app. Title music works out of the box; a SoundFont is already included.
